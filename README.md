# Login Functionality Testing Project

## Objective
To validate the login functionality by testing various user inputs, edge cases, and system behaviors.

## Scope
This project focuses on manual testing of the login feature, including:
- Positive testing (valid login)
- Negative testing (invalid inputs)
- Edge case testing (boundary values and unusual inputs)

## Test Coverage
The following areas were tested:
- Input validation (email and password)
- Error handling and validation messages
- Case sensitivity handling
- Boundary conditions (long inputs, empty fields)
- User interaction scenarios (keyboard input, repeated actions)

## Artifacts
- Test Cases: 8 structured test cases covering normal and edge scenarios  
- Bug Reports: 1 documented issue with clear reproduction steps  
- Test Scenarios: Comprehensive list of tested conditions  

## Tools Used
- Jira (for test management and bug tracking)
- GitHub (for documentation and portfolio presentation)

## Summary
This project demonstrates the ability to design test cases, identify edge cases, report bugs clearly, and document testing activities in a structured and professional manner.
